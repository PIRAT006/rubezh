# РУБЕЖ — 3D тактическая стратегия в браузере

Браузерная RTS про современный конфликт: река, мосты, господствующая высота,
опорные пункты, снабжение и бронетехника. Всё генерируется процедурно, звук
синтезируется через WebAudio, внешних ассетов нет — только `three.js` в `vendor/`.

## Запуск

Открыть `index.html` двойным кликом в Chrome/Edge/Firefox. Сервер не нужен:
все модули подключены обычными `<script>`, `three.js` лежит локально.

Если браузер блокирует `file://` (некоторые политики), можно поднять статику:

```powershell
python -m http.server 8000   # затем http://localhost:8000
```

## Управление

### Общее тактическое (RTS)

| Действие | Клавиши |
|---|---|
| **Вид от 1-го лица / Прямой контроль** | **`V`** (на выбранном юните или ближайшем союзнике) |
| **Вызов авиаудара** | **`Z`** (затем клик по цели / земле) |
| **Вызов артналёта** | **`X`** (тяжёлый залп по площади) |
| **Поставить дымзавесу** | **`C`** (маскировочный дым) |
| Выделение | ЛКМ; ЛКМ + протяжка — рамка; двойной клик — все такого типа |
| Добавить к выделению | `Shift` |
| Перемещение | ПКМ по земле |
| Атака цели | ПКМ по противнику |
| Атака по площади | `A`, затем ЛКМ по точке |
| Стоп / держать позицию / сбор | `S` / `H` / `F` |
| Группы | `Ctrl+1…9` назначить, `1…9` выбрать |
| Камера | `W` `A`(Shift) `S`(Shift) `D`, стрелки, край экрана |
| Поворот камеры | `Q` / `E` |
| Зум | колесо мыши |
| К штабу / в центр | `Space` / `Home` |
| Пауза / скорость | `P` / `T` |
| Звук / справка | `M` / `F1` |

### Режим от 1-го лица (Кокпит боевой машины / Пехота)

| Действие | Управление |
|---|---|
| Взгляд / наведение башни | Движение мыши (захват курсора) |
| Ход / поворот корпуса | `W` `S` (вперёд/назад), `A` `D` (поворот корпуса у танков / стрейф у пехоты) |
| Форсаж / бег | `Shift` |
| Огонь | **`ЛКМ`** (зажатие для непрерывного огня) |
| Оптика / Прицел с зумом | **`ПКМ`** (баллистическая сетка и лазерный дальномер) |
| Смена оружия (Осн. / Доп.) | **`1`** / **`2`** (пушка, спаренный пулемёт, автопушка, ПТУР) |
| Следующий / предыдущий юнит | **`Tab`** / **`Shift+Tab`** |
| Поддержка Ставки прямо из кабины | **`Z`** (авиаудар), **`X`** (артобстрел), **`C`** (дым) по перекрестию |
| Выход в стратегический режим | **`V`** или **`ESC`** |

## Механики и Экшен

- **Вид от первого лица (FPS)** — возможность в любой момент сесть за руль танка «Гранит», БМП «Рысь», ЗРК, САУ или лично вести отделение мотострелков. Реалистичная физика хода корпуса, поворот башни, отдача и тряска камеры, шкала дальномера и визор захвата целей.
- **Поддержка Ставки** — командирские вызовы за очки снабжения: вызов штурмовика с серией фугасных бомб, тяжёлый артобстрел по укреплениям и дымовая маскировка.
- **Хитмаркеры и сочность боя** — тактильный отклик при попадании по врагу, красный маркер и всплывающая плашка за уничтожение врага с премией снабжения, радиопереговоры экипажей.
- **Ветеранство юнитов** — за нанесённый урон и фраги юниты получают опыт и звания: **Новобранец** → **★ Ветеран** (+15% урон, +15% перезарядка) → **★★ Ас** (+30% урон, +30% перезарядка, золотые звёзды).
- **Взрывные волны и дымы** — деформирующие расширяющиеся ударные кольца от снарядов и авиабомб, объёмный дым и искры рикошетов.
- **Интуитивный интерфейс** — анимированные пунктирные линии приказов движения и атак, 3D полоски прочности над боевыми группами, удобная панель способностей.
- **Снабжение** — валюта. Приходит от штаба, складов и захваченных опорных пунктов.
- **Лимит личного состава** — растёт от построек (штаб, казармы, мастерские, склады).
- **Захват пунктов** — пехота и разведка в радиусе точки. Прогресс идёт от −100 (враг) до +100 (наш), за 0 — нейтрально. Присутствие обеих сторон блокирует захват.
- **Типы урона против брони** — пули почти не берут танки, ПТУР вскрывает броню, осколочные снаряды бьют пехоту, ПВО работает только по воздуху.
- **Артиллерия** — навесной огонь по площади, минимальная дистанция, РСЗО даёт залп.
- **Дроны** — барражирующие боеприпасы, уязвимы для ЗРК.
- **Туман войны** — обзор зависит от юнитов и зданий; рельеф перекрывает линию видимости.
- **Тактика рельефа** — склоны замедляют технику, река проходима только по мостам и броду, высота 112 даёт обзор и преимущество.

## Состав группировки

**«Союз» (игрок):** мотострелки, БМП «Рысь», ОБТ «Гранит», САУ «Молот»,
РСЗО «Шквал», ЗРК «Щит», разведка, дрон-камикадзе.

**«Консорциум» (ИИ):** те же типы, но с собственной экономикой, планом застройки
и волнами атак. Три уровня сложности меняют доход, темп и агрессию.

## Победа и поражение

Победа — уничтожить штаб противника (и лишить его армии). Поражение — потерять свой штаб.

## Структура

```
index.html          разметка HUD и меню
css/style.css       тактический интерфейс
vendor/three.min.js three.js r160 (UMD)
js/util.js          математика, шум, куча
js/terrain.js       рельеф, река, мосты, навигация, туман войны
js/models.js        низкополигональные модели техники и зданий
js/sprites.js       рисованные иконки для HUD
js/effects.js       частицы, трассеры, взрывы, воронки
js/path.js          A* по сетке навигации
js/units.js         юниты, постройки, оружие, поведение
js/game.js          состояние мира, экономика, бой, точки, условия победы
js/ai.js            командующий противника
js/camera.js        RTS-камера
js/input.js         мышь и клавиатура
js/ui.js            HUD, миникарта, панели, оверлеи
js/audio.js         процедурный звук
js/main.js          инициализация и главный цикл
tools/              автотесты на CDP (не нужны для игры)
```

## Тесты

В `tools/` лежат сценарии на Node + Chrome DevTools Protocol: прогон партии,
проверка ввода мышью, аудит интерфейса, баланс по сложностям.

```powershell
node tools/run-test.mjs .
node tools/input-test.mjs .
node tools/balance.mjs .
```

Для игры эти файлы не требуются — их можно удалить.
